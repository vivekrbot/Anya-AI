key How to get your free Groq API key
  1. Open console.groq.com/keys (opens in a new tab).
  2. Sign in with Google or GitHub — it's free and needs no credit card.
  3. Click Create API Key and give it a name (e.g. "Anya AI").
  4. Copy the key — it starts with gsk_.
  5. Paste it into the field above, then click Save Key and Test Key.

lock Your key is stored only on this device and is sent only to Groq to generate results. Text you process is sent to Groq when you trigger an action. No analytics or tracking. See our Groq's privacy policy.
